# Tools and Libraries

## 1. Hugging Face Transformers

Hugging Face Transformers is a widely used Python library for working with transformer-based language models.

**Purpose:** It can be used to load language models and conduct controlled experiments using different prompt formulations.

**Relevance:** Researchers can use it to compare model outputs across multiple prompt variants.

**Official Repository:**  
https://github.com/huggingface/transformers

---

## 2. OpenAI API

The OpenAI API provides programmatic access to large language models.

**Purpose:** It can be used to automatically submit multiple prompt variants and collect model responses.

**Relevance:** This makes it possible to perform systematic prompt-sensitivity experiments.

**Official Documentation:**  
https://platform.openai.com/docs

---

## 3. LangChain

LangChain is a framework for developing applications and experimental workflows involving large language models.

**Purpose:** It provides tools for prompts, chains, retrieval, and model interaction.

**Relevance:** Different prompt templates can be created and compared using structured workflows.

**Official Repository:**  
https://github.com/langchain-ai/langchain

---

## 4. LM Evaluation Harness

LM Evaluation Harness is a framework for evaluating language models on standardized benchmarks.

**Purpose:** It provides reproducible evaluation of language models across multiple tasks.

**Relevance:** Researchers can use standardized evaluation procedures to compare model performance under different prompting conditions.

**Official Repository:**  
https://github.com/EleutherAI/lm-evaluation-harness

---

## 5. Promptfoo

Promptfoo is a framework for testing and evaluating LLM prompts.

**Purpose:** It allows users to compare different prompts and model outputs.

**Relevance:** It is directly useful for studying prompt sensitivity because multiple prompt variants can be evaluated systematically.

**Official Repository:**  
https://github.com/promptfoo/promptfoo
