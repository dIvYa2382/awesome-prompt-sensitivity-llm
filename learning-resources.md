# Learning Resources

This section contains tutorials, courses, and practical learning resources for understanding Large Language Models, prompt engineering, evaluation, and prompt sensitivity.

---

## 1. Hugging Face LLM Course

**Provider:** Hugging Face

**Level:** Beginner to Advanced

**Description:**  
The Hugging Face LLM Course provides practical and theoretical learning about Large Language Models, Transformer models, tokenization, datasets, fine-tuning, and reasoning models.

**Why it is useful for this topic:**  
It provides the technical foundation needed to understand how LLMs work and how experiments involving prompts and model outputs can be conducted.

**Resource:**  
https://huggingface.co/learn/llm-course/

---

## 2. OpenAI Prompt Engineering Guide

**Provider:** OpenAI

**Description:**  
An official guide covering practical techniques for writing clear and effective prompts, including specifying instructions, providing context, and refining prompts iteratively.

**Why it is useful for this topic:**  
Prompt sensitivity is closely related to how changes in instructions, context, and formatting influence model outputs.

**Resource:**  
https://help.openai.com/en/articles/6654000-best-prompt-gineering-with-the-openai-api

---

## 3. ChatGPT Prompt Engineering for Developers

**Provider:** DeepLearning.AI and OpenAI

**Instructors:** Isa Fulford and Andrew Ng

**Level:** Beginner

**Duration:** Approximately 1 hour 30 minutes

**Description:**  
A practical short course covering prompt engineering principles, iterative prompting, summarization, inference, transformation, expansion, and building a custom chatbot.

**Why it is useful for this topic:**  
The course provides hands-on experience with writing and iterating prompts, which is directly relevant to studying prompt sensitivity.

**Resource:**  
https://www.deeplearning.ai/courses/chatgpt-prompt-eng/

---

## 4. Stanford CS25 — Transformers United

**Provider:** Stanford University

**Description:**  
Stanford CS25 is a seminar course covering Transformer research and applications, including Large Language Models and recent developments in the field.

**Why it is useful for this topic:**  
It provides deeper technical understanding of Transformer architectures and LLM research, which forms the foundation for understanding prompt-based behaviour.

**Resource:**  
https://web.stanford.edu/class/cs25/

**Lecture Recordings:**  
https://web.stanford.edu/class/cs25/recordings/

---

## 5. OpenAI Cookbook

**Provider:** OpenAI

**Description:**  
The OpenAI Cookbook contains practical examples and guides for building applications with language models, including prompting, evaluation, optimization, agents, and reliability.

**Why it is useful for this topic:**  
The cookbook contains practical material on evaluating and improving prompt reliability, making it useful for experiments involving prompt stability.

**Resource:**  
https://cookbook.openai.com/

---

## 6. Building Resilient Prompts Using an Evaluation Flywheel

**Provider:** OpenAI Cookbook

**Description:**  
This practical guide explains how to evaluate and improve prompt resilience using a continuous evaluation process.

**Why it is useful for this topic:**  
Prompt resilience is closely related to prompt stability. The resource explains how systematic evaluation can identify cases where small changes in input or context cause unexpected model behaviour.

**Resource:**  
https://github.com/openai/openai-cookbook/blob/main/examples/evaluation/Building_resilient_prompts_using_an_evaluation_flywheel.md
